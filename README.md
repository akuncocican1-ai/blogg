# Ruang Sela

Blog editorial ringan tentang cerita digital, kreator, dan hal-hal kecil di internet.

## Menjalankan lokal

Buka `index.html` di browser. Fitur embed TikTok memerlukan koneksi internet dan tautan video TikTok publik dengan format lengkap.

## Publikasi

GitHub Pages menerbitkan situs secara otomatis dari branch `main` melalui GitHub Actions. Alamat situs:

https://akuncocican1-ai.github.io/blogg/

Jika Pages belum aktif di pengaturan repo, aktifkan Pages dengan sumber **GitHub Actions**. Setelah workflow selesai, situs dapat diakses dari internet.
